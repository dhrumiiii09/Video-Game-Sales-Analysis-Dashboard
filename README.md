# 🎮 Video Game Sales & Performance Analysis

Interactive Power BI dashboard for analyzing video game sales, platform performance, game genres, developer contributions, regional sales, and critic ratings using Power Query, DAX, and Star Schema data modeling.

# Project Overview

This project focuses on analyzing video game sales, gaming platforms, genres, developers, regional performance, and critic reviews using Microsoft Power BI.

The objective is to transform raw video game data into meaningful insights through data cleaning, data modeling, DAX calculations, and interactive dashboards.

The dashboard provides an overview of global video game sales, identifies top-performing games and developers, compares gaming platforms, and analyzes regional sales and critic scores.

# Tools Used

- Power BI Desktop
- DAX
- Data Transformation & Modeling

# Objectives

- Analyze overall video game sales performance.
- Identify the best-selling games and gaming consoles.
- Compare game sales across different genres.
- Analyze top developers based on sales.
- Evaluate regional sales performance.
- Understand critic scores across different game genres.
- Build an interactive dashboard for data-driven decision-making.
